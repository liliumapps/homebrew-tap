# Lilium Apps Homebrew Tap

Homebrew casks and formulas for [Lilium Apps](https://liliumapps.com) tools.

## Install a package

Install a package directly from this tap:

```sh
brew install --cask liliumapps/tap/commando
```

Alternatively, add the tap once and install packages by name:

```sh
brew tap liliumapps/tap
brew install --cask commando
```

Package definitions in `Casks/` and `Formula/` are updated by their source
projects' release workflows.
